# 🛒 Full-Stack E-Commerce Website  

A **full-stack e-commerce platform** built using **MERN stack** (MongoDB, Express.js, React, Node.js). This project provides a modern, secure, and responsive shopping experience with features for both customers and admins.  

---

## ✨ Features  

- **Product Listings & Management (Admin)**  
  Admins can add, update, and manage product details seamlessly.  

- **Secure Authentication**  
  Implemented **JWT authorization** for safe login/signup and role-based access control.  

- **Shopping Cart & Checkout**  
  Users can add products to cart, update quantities, and complete checkout with ease.  

- **Responsive Design**  
  Optimized for desktop, tablet, and mobile devices.  

---

## 🛠️ Tech Stack  

- **Frontend:** React.js (dynamic & responsive UI)  
- **Backend:** Node.js & Express.js (efficient server & API handling)  
- **Database:** MongoDB (secure, scalable data storage)  
- **Authentication:** JWT (JSON Web Token) for secure user sessions  

---

## 📌 Project Highlights  

- Secure **user authentication and role-based access control**.  
- Smooth integration of frontend, backend, and database.  
- Admin panel for **product management**.  
- Fully functional **cart and checkout workflow**.  
- Modern **responsive UI** for a seamless experience.
